# Number Guessing Game 🎮

## About the Project

This is a simple Number Guessing Game developed using Python and NumPy. The computer generates a random number between 1 and 100, and the player has to guess it within a limited number of attempts.

## Features

* Random number generation.
* Three difficulty levels:

  * Easy – 10 chances
  * Medium – 5 chances
  * Hard – 3 chances
* Hints indicate whether the correct number is higher or lower than the guess.
* Displays the number of attempts taken.
* Displays the time taken to complete the game.
* Option to play again.

## Technologies Used

* Python
* NumPy
* Time module

## How to Run

1. Install Python.

2. Install NumPy using:

   `pip install numpy`

3. Run the Python file:

   `python number_guessing_game.py`
